Live n8n Webhook - Version 2.1

HR Agent V2.1 Live CV Screening

Submit a PDF CV from this website into the activated n8n workflow. The workflow extracts the CV text, scores the candidate with an AI agent, validates the result, logs the evaluation, and emails the recruiter only for shortlist outcomes.

Back To Project Card V2.1 Workflow JSON

What Runs Behind The Form

The webpage posts to the site backend, which forwards the CV to the production webhook path on the ngrok-hosted n8n instance. No CV is stored by GitHub Pages.

Website Input

The form sends candidate details and the PDF file as multipart form data to the live n8n webhook.

Agentic Screening

n8n passes the PDF to OCR, then asks the AI agent to score the candidate against the role rubric.

Controlled Side Effects

Deterministic nodes validate totals, log the result, and keep recruiter email limited to shortlist decisions.
